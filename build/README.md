# Android APK build

The installable APK is produced by Expo EAS with:

```powershell
cd mobile
npx eas-cli@latest build --platform android --profile production
```

EAS build `c4325b5f-df2a-4a3d-a899-94a9adeac6c5` is queued. Copy the downloaded
artifact here as `AgriSokoPocket_G11.apk` only after the cloud build succeeds.
The repository does not include a fabricated or placeholder APK.
