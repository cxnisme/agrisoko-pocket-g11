# Evidence and sign-off

Store evidence only after it has been observed and checked. A blank field means
the item is pending; do not replace it with a guessed or success-shaped result.

Before release:

- Each member must review and approve their own profile claims.
- Record actual test commands, environment versions, pass/fail output, and
  relevant artifact paths.
- Record device model, Android version, APK build identifier, and manual test
  outcomes only after the test has been performed.
- Record tester feedback only with that tester's consent; do not include private
  contact details.
- Link each contribution to its real issue, branch, pull request, merged commit,
  and (when available) demonstration timestamp.
- Do not commit API tokens, passwords, signing keys, or other secrets.

Christian owns the final integration/build/release evidence.
